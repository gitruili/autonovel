# Prompt 模板：质量评估

> 源文件: `evaluate.py`
> System Prompt: `"你是一位严苛但公正的{genre.display_name}网文评论家。"`
> 注意: evaluate.py 包含大量机械化检测逻辑（不需要 LLM），只有最终打分部分使用 LLM

---

## 机械化检测（不需要 LLM，直接运行脚本）

以下检测可以直接运行 `uv run python evaluate.py --chapter=N`：

### TIER 1 违禁词（见到就扣分）
不禁、映入眼帘、心中一动、不由自主、若有所思、心下了然、暗自思忖、缓缓开口、
一股暖流涌上心头、美眸、玉手、樱唇、宛如仙子、谪仙、目光如炬、眸光一闪

### TIER 2 叠词（单独无害，扎堆可疑）
暗暗、默默、悄悄、淡淡、微微、隐隐、丝丝、幽幽、轻轻、款款、盈盈、楚楚、脉脉、袅袅
（一段内 3 个以上 = 扣分）

### TIER 3 废话句式
她心想、她不知道的是、时间仿佛凝固、她从未想过自己会、一切都在朝着好的方向发展、
这一刻终于明白、生活不就是这样吗、他就这样静静地看着、仿佛回到了的时光

## LLM 评估维度（需要生成内容时使用）

### Foundation 阶段评估维度（从 genre YAML evaluation.foundation 加载）

通用维度：
- **角色深度** — 每个主要角色是否有完整驱动力链条？
- **角色辨识度** — 去掉对话标签能否辨认说话者？
- **角色秘密** — 秘密是否具体？暴露后是否会改变关系线？
- **大纲完整性** — 每章是否有核心推进线、章尾钩子？
- **伏笔平衡** — 伏笔台账是否存在？植入到回收间隔3章以上？
- **内部一致性** — 物价、时间线、角色年龄是否自洽？
- **语气清晰度** — 语气定义是否具体？
- **准则覆盖度** — 事实是否被完整记录？

### Chapter 阶段评估维度
- **章尾钩子** — 结尾是否让人想继续阅读？
- **场景比例** — 至少 70% 的内容是否在即时场景中？
- **对话质量** — 对话是否像人说话？
- **感官细节** — 是否有具体的感官描写？
- **AI废话密度** — 是否包含违禁词和废话句式？

### 评分标准
每个维度 1-10 分，加权平均得出 overall_score。
- 8.0+ = 优秀
- 7.0-7.9 = 合格
- 6.0-6.9 = 需要修订
- < 6.0 = 需要重写

## 评估 Prompt 模板

```
你是一位严苛但公正的{genre.display_name}网文评论家。请对以下章节进行多维度评估。

=== 章节内容 ===
{chapter_text}

=== 评估维度 ===
（从 genre YAML evaluation 部分动态加载维度和描述）

请为每个维度打分（1-10），并给出具体的改进建议。
输出格式：
维度名: 分数
...
overall_score: 加权平均分
callouts:
- 具体问题描述和改进建议
```
